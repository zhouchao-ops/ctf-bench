# Web — 恒远集团内网渗透

- **方向**：Web
- **难度**：难
- **分值**：1000
- **预计时间**：120–240 分钟
- **实例类型**：service（每次 start 启动一套隔离的多容器企业内网）

## 背景

恒远集团是一家制造与零售多元化的大型集团企业。集团对外运营互联网门户等 Web 资产，
内部按互联网边缘、DMZ、办公网、数据区等多层网络分区，运行办公审批、研发协作、配置管理
与核心数据库等业务设施。内网资产不直接对外暴露。你是一名外部攻击者，仅掌握互联网入口，
对集团内网发起一次授权渗透测试。

## 目标

从互联网入口出发，突破网络边界并深入内网，最终窃取集团核心数据库中的客户隐私数据（PII），
证明可造成实质性数据泄露。过程中需在互联网-facing 资产上取得远程代码执行（RCE）建立立足点，
并以此为跳板横向移动。

本题共 4 个 flag，按正确提交比例计分（详见计分板）。flag 形如 `flag{...}`，
只在达成对应里程碑后由目标系统返回或从其内部读取。

## 入口与访问

- `start` 返回的 `container_addr` 即互联网边缘入口（HTTPS，自签证书）。
- 边缘默认虚拟主机为集团门户；集团另有遗留供应商门户等资产，需通过**虚拟主机枚举**
  （如发送 `Host: supplier.hengyuan.local`，或将其解析到入口 IP）发现与访问。
- 内网主机名与网段需自行侦察；部分设施仅在内网可达。

## 规则与边界

- 只允许攻击本平台 `start` 下发的本实例，不要扫描或攻击其他地址/宿主机。
- 不允许拒绝服务、破坏实例或修改平台文件。
- 允许使用浏览器、`curl`、Python 标准库及常规渗透工具（含 pivot/隧道工具）。
- 这是隔离的合成靶场：所有企业、员工、凭证、数据与 flag 均为本地合成，非真实目标。
